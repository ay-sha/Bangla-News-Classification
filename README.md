# Bangla-News-Classification
# Overview
Bangla News Classification is an NLP (Natural Language Processing) project built using Python. The goal is to classify Bangla news articles into predefined categories using machine learning techniques. This project utilizes various text preprocessing steps, feature extraction methods, and machine learning algorithms to achieve high accuracy in classifying Bangla news.

# Features
1. Text Preprocessing: Tokenization, stopword removal, stemming, and lemmatization for Bangla text.
2. Feature Extraction: TF-IDF (Term Frequency-Inverse Document Frequency) vectorization for text representation.
3. Classification Models: Includes algorithms like MultinomialNB, LogisticRegression, Decision Tree Classifier, and Random Forest.
4. Performance Metrics: Accuracy, precision, recall, and F1 score for model evaluation.
# Technologies Used
1. Programming Language: Python
2. Libraries:
      1. NLP: NLTK (Natural Language Toolkit), BanglaNLP
      2. Machine Learning: Pandas, NumPy
      3. Visualization: Matplotlib, Seaborn
      4. Text Vectorization: Scikit-learn’s TF-IDF Vectorizer
